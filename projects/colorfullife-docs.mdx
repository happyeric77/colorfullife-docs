## What it is

ColorfulLife Docs is the site you are reading. It started as a pile of
technical notes and is being rebuilt as a **project-first engineering
journal**: what I build, what happened while building it, and which
technologies show up across projects.

## Structure

The site has four content systems:

- **Projects** — the entities, like this one.
- **Journal** — dated entries produced by the work.
- **Topics** — cross-project discovery paths (Docusaurus, Kubernetes, GitOps).
- **Archive** — the legacy technical notes, kept for reference.

## Story

The original site was documentation-only: every note was a page in one big
docs tree. That worked for reference, but it had no place for the actual
work — the decisions, dead ends and retrospectives. The rebuild introduces
Projects and a Journal without deleting or rewriting the archive.
